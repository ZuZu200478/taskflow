# TaskFlow－智慧任務管理器

TaskFlow 是一個管理課業、研究、工作與生活事項的互動式 Web App。
透過任務卡片、日曆、時間軸與優先矩陣，協助使用者安排任務的處理順序。

## 網站連結
https://github.com/ZuZu200478/taskflow

## 製作動機

一般待辦清單只能記錄事項與完成狀態，難以判斷處理順序。
因此，我希望結合重要性、緊急度、難度與截止時間，
讓使用者更直覺地管理多項任務。

## 主要功能

- 新增、編輯與刪除任務。
- 任務狀態：待辦、進行中、已完成、已結案。
- 群組分類：課業、研究、工作、社團、生活。
- 設定重要性（1～5級）、緊急度（1～5級）與難度（1～3級）。
- 左側統計顯示各狀態數量與今日完成率。
- 搜尋任務，依屬性篩選與排序。
- 日曆可切換月份，點選日期查看當天到期的任務。
- 時間軸依截止日期與時間排列任務。
- 優先矩陣呈現「重要性 × 時間壓力」，
  點選任務點可查看詳細資訊。
- 使用 LocalStorage 保存資料。
- 支援電腦與手機版面。

## 優先矩陣計算方式

X 軸為重要性，越靠右越重要。
Y 軸為系統依截止時間計算的時間壓力，越靠下越緊迫。

剩餘 7 天以上的任務位於上方；
隨著截止時間接近，位置逐漸向下移動；
已逾期任務位於底部。

主觀緊急度另行記錄，可用於篩選與排序。

## 今日完成率

以「今日到期或今日完成的任務」為統計範圍，
計算其中已完成或已結案的比例。
沒有符合條件的任務時顯示 0%。

## 使用方式

1. 點選「＋新增任務」，輸入任務資訊。
2. 利用列表、日曆、時間軸或優先矩陣查看任務。
3. 開始處理時標記為「進行中」。
4. 完成後標記為「已完成」，確認結束後再結案。
5. 在「已結案」頁面查看歷史紀錄。

## 技術與檔案

使用 HTML、CSS、JavaScript 與 LocalStorage。
所有網頁程式碼整合在單一 index.html，
不需要後端伺服器，透過 GitHub Pages 公開網站。

## 資料保存限制

任務資料只保存在目前使用的瀏覽器中，
不會同步至 GitHub 或其他裝置。
更換瀏覽器、裝置或清除網站資料後，原紀錄不會保留。
